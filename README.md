# เช็กลิสต์งานป้ายและสติกเกอร์

เว็บเช็กลิสต์ติดตามงานป้ายและสติกเกอร์ รวม 163 ชิ้น พร้อมบอร์ด `ตัดตามขนาด` สำหรับติ๊กยืนยันการตัด

## ฟังก์ชันหลัก

- เช็กลิสต์แยกตามหมวดงาน
- บันทึกสถานะในอุปกรณ์อัตโนมัติ
- บอร์ดตัดตามขนาด พร้อม KPI: งานตัดทั้งหมด / ตัดแล้ว / คงเหลือ
- รองรับการใช้งานบนมือถือและเดสก์ท็อป

เปิดไฟล์ `index.html` เพื่อใช้งานได้ทันที
